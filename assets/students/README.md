# assets/students — รูปโปรไฟล์นักศึกษา

วางรูปไว้ในโฟลเดอร์นี้ โดยตั้งชื่อไฟล์ตาม **รหัสนักศึกษา** ที่อยู่ในฐานข้อมูล Neo4j

ตัวอย่าง

- `assets/students/S001.jpg` → รูปของ Anan (รหัส S001)
- `assets/students/default.png` → รูปสำรอง ใช้กับทุกคนที่ยังไม่มีรูปของตัวเอง

กติกา

- นามสกุลที่รองรับ: `.png`, `.jpg`, `.jpeg`, `.webp`
- แนะนำรูปสี่เหลี่ยมจัตุรัส (เช่น 512×512) เพราะโค้ดจะครอปเป็นวงกลม (`object-fit: cover`)
- รูปจะถูกอ่านเป็น base64 แล้วฝังในหน้าเว็บ จึงไม่ต้องเปิด public URL ให้รูป

หลังวางไฟล์แล้วให้ `git add assets/students` เพื่อให้ Streamlit Cloud เห็นไฟล์ด้วย
